# Security policy

JournaLLM is designed to run locally and handles very personal data, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Report privately through
[GitHub private vulnerability reporting](https://github.com/umute97/journaLLM/security/advisories/new).

Include what you found, how to reproduce it, and the affected version (see `/api/v1/health`).
You can expect an initial response within a week.

## Supported versions

Only the latest release receives fixes.
